# IP Checker Website с интеграцией 3x-ui

Простой веб-сайт на Python (Flask), отображающий IP-адреса пользователя. Развернут в изолированной Docker-сети со статическим IP `10.0.0.2`.

## Структура проекта

* `app.py`: Flask приложение.
* `Dockerfile`: Конфигурация образа.
* `docker-compose.yml`: Конфигурация сети и контейнера.

## 1. Развертывание (Docker)

### Предварительные требования
* Docker и Docker Compose должны быть установлены.

### Запуск

1. Перейдите в папку проекта:
   ```bash
   cd c:\Users\User\Desktop\corpSite
   ```

2. Запустите контейнер:
   ```bash
   docker-compose up -d --build
   ```

3. Проверьте статус:
   ```bash
   docker ps
   ```
   Контейнер `ip_checker_site` должен работать.

## 2. Настройка сети

В `docker-compose.yml` настроена сеть `private_net` с подсетью `10.0.0.0/24`.
* **IP Контейнера:** `10.0.0.2`
* **Шлюз:** `10.0.0.1`

> **Важно:** Мы использовали маску `/24` (255.255.255.0) вместо `/32`, так как Docker требует минимальный размер подсети для создания шлюза и broadcast-адреса. `/32` содержит только 1 IP адрес, что технически невозможно для создания работоспособной сети с взаимодействием.

## 3. Интеграция с 3x-ui (Outbound / Routing)

Чтобы пользователи вашего VPN (Xray/3x-ui) могли попадать на этот сайт по IP `10.0.0.2`, нужно настроить маршрутизацию.

**Предполагается, что 3x-ui также запущен в Docker или имеет доступ к сети хоста Docker.**

### Вариант А: Если 3x-ui в том же Docker Compose (рекомендуется)
Добавьте контейнер 3x-ui в ту же сеть `private_net` в вашем docker-compose файле.

### Вариант Б: Настройка Routing Rules (Xray Config)

В панели 3x-ui перейдите в **Settings -> Xray Configuration -> Routing Rules**.

Вам нужно добавить правило, которое направляет трафик для `10.0.0.2` напрямую (freedom) или на специфический outbound.

Но чаще всего, если сайт локальный, достаточно просто разрешить доступ к приватным IP.

**Пример конфигурации Routing (в формате JSON для Xray):**

```json
{
  "routing": {
    "rules": [
      {
        "type": "field",
        "ip": ["10.0.0.2"],
        "outboundTag": "direct"
      }
    ]
  }
}
```

*Примечание:* Если 3x-ui запущен на хосте (не в докере), вам может потребоваться добавить статический маршрут на сервере, чтобы хост знал, где искать `10.0.0.0/24`:
```bash
# Пример команды для Linux хоста (если Docker не прописал маршруты сам)
ip route add 10.0.0.0/24 dev docker0
```

## 4. Проверка работоспособности

1. Подключитесь к вашему VPN/Proxy (клиент v2ray/Xray).
2. Попробуйте открыть в браузере: `http://10.0.0.2`.
3. Если маршрутизация настроена верно, вы увидите страницу с вашими IP-адресами.
