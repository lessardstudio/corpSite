# IP Checker Website (VPN Access Only)

Простой веб-сайт на Python (Flask), отображающий IP-адреса пользователя.

**Режим безопасности:**
*   **Публичный доступ:** ОТКЛЮЧЕН.
*   **Доступ из VPN:** РАЗРЕШЕН.

## 1. Развертывание

```bash
docker-compose down -v
docker-compose up -d --build
```

## 2. Доступ к сайту

У вас есть два варианта доступа через VPN:

### Вариант А: Прямой Docker IP (простой)
Если ваш VPN-клиент маршрутизирует все приватные сети, просто откройте:
`http://172.25.0.2`

### Вариант Б: Виртуальный IP 10.60.0.3 (красивый)
Если вы хотите, чтобы сайт был доступен по адресу из вашей VPN-подсети (`10.60.0.3`), выполните скрипт настройки на сервере:

```bash
chmod +x setup_virtual_ip.sh
sudo ./setup_virtual_ip.sh
```

После этого сайт будет доступен по адресу: `http://10.60.0.3`

## 3. Диагностика VPN (на стороне Клиента)

Ваши настройки клиента выглядят корректно:
*   **IP:** `10.60.0.2` (Ваш адрес)
*   **Маска:** `255.255.255.0` (/24)

Если сайт не открывается, проверьте:
1.  **Ping:** `ping 10.60.0.1` (шлюз VPN)
2.  **Ping Virtual IP:** `ping 10.60.0.3` (если настроили Вариант Б)
3.  **Маршруты в клиенте:** Убедитесь, что ваш VPN-клиент (Hysteria/Xray) перехватывает трафик для `10.60.0.0/24`.

## 4. Структура проекта
* `docker-compose.yml`: Конфигурация Docker (сеть `172.25.0.0/24`).
* `setup_virtual_ip.sh`: Скрипт для маппинга `10.60.0.3` -> `172.25.0.2`.
