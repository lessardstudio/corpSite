# IP Checker Website (ZeroTier Support)

Простой веб-сайт на Python (Flask), отображающий IP-адреса пользователя.

**Конфигурация:**
*   **Docker сеть:** `10.200.0.0/24` (изолированная).
*   **Доступ:** Порт 80 проброшен на хост.
*   **Совместимость:** ZeroTier (ztnet), VPN, LAN.

## 1. Развертывание

```bash
docker-compose down -v
docker-compose up -d --build
```

## 2. Доступ через ZeroTier (ztnet)

Чтобы сайт был доступен устройствам в вашей сети ZeroTier (`172.25.28.x`):

1.  Убедитесь, что Docker-контейнер запущен.
2.  Узнайте **ZeroTier IP адрес** вашего компьютера (хоста), на котором запущен Docker.
    *   *На Windows:* `ipconfig` (Ищите адаптер ZeroTier One).
    *   *На Linux:* `ip addr show` (Ищите интерфейс `zt...`).
    *   *Из панели ZeroTier:* Посмотрите IP в колонке "Managed IPs" (например, `172.25.28.41`).
3.  С других устройств открывайте сайт по этому IP:
    👉 `http://172.25.28.41` (замените на ваш реальный IP)

## 3. Важные изменения

*   **Смена подсети:** Мы перенесли Docker в подсеть `10.200.0.0/24`, так как предыдущая (`172.25.0.0/24`) конфликтовала с вашей сетью ZeroTier (`172.25.x.x`).
*   **Порт 80:** Порт открыт на всех интерфейсах хоста.

## 4. Если сайт не открывается

1.  **Firewall (Брандмауэр):**
    *   *Windows:* Убедитесь, что Брандмауэр Windows не блокирует входящие подключения к Python/Docker на порту 80.
    *   *Linux:* Проверьте `ufw` или `iptables`.
2.  **Ping:** Попробуйте пропинговать IP хоста с другого устройства ZeroTier.
