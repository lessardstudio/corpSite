# IP Checker Website (ZeroTier Support)

Простой веб-сайт на Python (Flask), отображающий IP-адреса пользователя.

**Конфигурация:**
*   **Docker сеть:** `10.200.0.0/24` (изолированная).
*   **Доступ:** Порт 80 проброшен на хост.
*   **Совместимость:** ZeroTier (ztnet), VPN, LAN.

## 1. Подключение VPS к ZeroTier

Чтобы ваш VPS стал частью сети ZeroTier, выполните следующие действия прямо на сервере.

### Шаг 1: Подключение
Используйте подготовленный скрипт:

```bash
chmod +x join_zerotier.sh
# Замените NETWORK_ID на ваш ID сети (можно найти в панели ZeroTier сверху)
sudo ./join_zerotier.sh <ВАШ_NETWORK_ID>
```

### Шаг 2: Авторизация
1.  Скрипт выведет ваш **Node ID** (например, `a1b2c3d4e5`).
2.  Зайдите в панель управления ZeroTier (откуда был скриншот).
3.  Найдите этот ID в списке устройств.
4.  Поставьте галочку **Auth** (Авторизован).
5.  Дождитесь, пока серверу назначится IP (например, `172.25.28.50`).

## 2. Развертывание сайта

```bash
docker-compose down -v
docker-compose up -d --build
```

## 3. Доступ к сайту

Теперь сайт доступен всем участникам вашей сети ZeroTier по IP-адресу, который ZeroTier выдал вашему VPS.

Пример: `http://172.25.28.50` (Замените на реальный IP, выданный VPS).

## 4. Структура проекта

* `docker-compose.yml`: Конфигурация Docker.
* `join_zerotier.sh`: Скрипт для установки и настройки ZeroTier.
