# IP Checker Website (Internal / VPN Only)

Простой веб-сайт на Python (Flask), отображающий IP-адреса пользователя.
**Конфигурация: Безопасный режим (Internal Only).**

Сайт развернут в изолированной сети `10.60.0.0/24` с IP `10.60.0.3` и **не доступен** из публичного интернета напрямую. Доступ возможен только через VPN (Hysteria2/Xray) или с хоста.

## Структура проекта

* `app.py`: Flask приложение.
* `Dockerfile`: Конфигурация образа.
* `docker-compose.yml`: Конфигурация сети (без публикации портов).
* `deploy.sh`: Скрипт развертывания.

## 1. Развертывание

```bash
chmod +x deploy.sh
./deploy.sh
```

После запуска `docker ps` не должен показывать порты в колонке `PORTS` (кроме внутренних).

## 2. Настройка доступа через Hysteria2 (TUN-режим)

Для доступа к сайту `http://10.60.0.3` ваш VPN-клиент (Hysteria2) должен работать в режиме **TUN** (или System Proxy) и маршрутизировать трафик для приватных подсетей в туннель.

### На стороне Клиента (Hysteria2 Client Config)

Убедитесь, что в конфигурации клиента включен режим TUN и маршрутизация.

**Пример (config.yaml):**

```yaml
tun:
  name: hysteria-tun
  mtu: 1500
  auto: true # Автоматически настраивает маршруты

# Если auto: false, вам нужно вручную добавить маршрут для 10.60.0.0/24
```

Если вы используете клиент с правилами маршрутизации (например, v2rayN, Nekobox или встроенные правила ACL), убедитесь, что IP `10.60.0.3` **отправляется в прокси (Proxy)**, а не в Direct.

*   **Правило:** `IP-CIDR,10.60.0.0/24,PROXY`

### На стороне Сервера (Hysteria2 Server)

Сервер Hysteria2 должен уметь отправлять трафик на локальные Docker-адреса. Обычно это работает "из коробки" на Linux, если включен ip_forward.

1.  Проверьте форвардинг: `sysctl net.ipv4.ip_forward` (должно быть `1`).
2.  Если сервер Hysteria2 запущен в Docker, он должен быть в одной сети с сайтом ИЛИ использовать сеть `host`.
3.  Если сервер Hysteria2 запущен как systemd сервис (на хосте), он видит сеть `10.60.0.0/24` через интерфейс моста docker.

## 3. Проверка безопасности

1.  **Прямой доступ закрыт:** Попробуйте открыть `http://<IP-ВАШЕГО-VPS>:80` или `8080`. Сайт открываться не должен.
2.  **Доступ через VPN работает:** Подключите VPN (Tun mode) и откройте `http://10.60.0.3`. Сайт должен открыться.
