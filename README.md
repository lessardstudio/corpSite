# IP Checker Website (ZeroTier Inside Docker)

Простой веб-сайт на Python (Flask), отображающий IP-адреса пользователя.

**Конфигурация:**
*   **ZeroTier:** Работает **внутри** контейнера. Контейнер получает свой собственный IP в вашей сети `ztnet`.
*   **Docker сеть:** `10.200.0.0/24`.

## 1. Настройка

1.  Откройте `docker-compose.yml`.
2.  Найдите строку `ZT_NETWORK_ID=...` и вставьте туда **ID вашей сети** (16 символов, из панели ZeroTier).

## 2. Запуск

```bash
docker-compose down -v
docker-compose up -d --build
```

## 3. Авторизация в ZeroTier

Поскольку ZeroTier теперь работает внутри контейнера, это **новое устройство** для вашей сети.

1.  Посмотрите логи, чтобы узнать Node ID:
    ```bash
    docker logs ip_checker_site
    ```
    Вы увидите что-то вроде:
    ```
    ZeroTier Node ID:
    a1b2c3d4e5
    ```

2.  Зайдите в панель управления ZeroTier (my.zerotier.com).
3.  Найдите устройство с этим ID и поставьте галочку **Auth**.
4.  Подождите пару минут и обновите страницу. Устройству будет назначен IP (например, `172.25.28.55`).

## 4. Доступ к сайту

Теперь сайт доступен по **этому новому IP**, который ZeroTier выдал контейнеру.
👉 `http://172.25.28.55` (пример)

Вам больше не нужно пробрасывать порты или настраивать IP хоста. Контейнер является полноценным участником VPN-сети.
