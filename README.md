# IP Checker Website

Простой веб-сайт на Python (Flask), отображающий IP-адреса пользователя.

**Режимы работы:**
1. **Public:** Доступен из Интернета (порт 80).
2. **Internal/VPN:** Доступен через VPN (IP `172.25.0.2` или IP сервера).

> **Важно:** Подсеть Docker изменена на `172.25.0.0/24`, чтобы избежать конфликтов с адресами VPN-клиентов (`10.60.0.0/24`).

## 1. Настройка для Публичного доступа (Public Access)

Чтобы сайт был доступен из интернета, выполните следующие шаги.

### Шаг 1: Настройка Firewall (Брандмауэра)
Выполните скрипт для открытия порта 80 на сервере:
```bash
chmod +x setup_firewall.sh
sudo ./setup_firewall.sh
```
> **Важно:** Если у вашего VPS провайдера (AWS, Google Cloud, Oracle) есть внешний фаервол (Security Groups), откройте порт 80 (HTTP) и там.

### Шаг 2: Запуск

#### Вариант А: Docker (Рекомендуется)
В `docker-compose.yml` настроен проброс порта 80 и безопасная подсеть.
```bash
docker-compose up -d --build
```

#### Вариант Б: Native (Без Docker)
Скрипт `run_native.sh` запускает сервер на всех интерфейсах (`0.0.0.0`).
```bash
sudo ./run_native.sh
```

### Шаг 3: Проверка
Откройте в браузере IP вашего сервера: `http://<ВАШ_ПУБЛИЧНЫЙ_IP>`.
Также доступно по внутреннему IP Docker: `http://172.25.0.2`.

## 2. Структура проекта

* `app.py`: Основной код приложения.
* `setup_firewall.sh`: Настройка iptables/ufw для открытия порта 80.
* `run_native.sh`: Скрипт запуска без Docker.
* `deploy.sh`: Скрипт запуска в Docker (с очисткой).
