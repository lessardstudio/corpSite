# IP Checker Website (VPN Access Only)

Простой веб-сайт на Python (Flask), отображающий IP-адреса пользователя.

**Режим безопасности:**
*   **Публичный доступ:** ОТКЛЮЧЕН.
*   **Доступ из VPN:** РАЗРЕШЕН.

## 1. Развертывание

```bash
docker-compose down -v
docker-compose up -d --build
```

## 2. Доступ к сайту

Используйте прямой Docker IP:
👉 `http://172.25.0.2`

> **Примечание:** Мы используем подсеть `172.25.0.0/24`, чтобы избежать конфликтов с вашей VPN-подсетью `10.60.0.0/24`.

## 3. Отмена настроек виртуального IP

Если вы ранее запускали `setup_virtual_ip.sh` и хотите всё вернуть как было:

```bash
chmod +x cleanup_virtual_ip.sh
sudo ./cleanup_virtual_ip.sh
```

## 4. Диагностика VPN (на стороне Клиента)

Если `http://172.25.0.2` не открывается:
1.  **Ping:** `ping 10.60.0.1` (шлюз VPN должен отвечать).
2.  **Маршруты:** Убедитесь, что VPN-клиент настроен на перехват приватных сетей (`172.16.0.0/12`).

## 5. Структура проекта
* `docker-compose.yml`: Конфигурация Docker (сеть `172.25.0.0/24`).
* `cleanup_virtual_ip.sh`: Скрипт для удаления виртуального IP `10.60.0.3`.
