# IP Checker Website (VPN Access Only)

Простой веб-сайт на Python (Flask), отображающий IP-адреса пользователя.

**Режим безопасности:**
*   **Публичный доступ:** ОТКЛЮЧЕН.
*   **Доступ из VPN:** РАЗРЕШЕН (только для подсети `10.60.0.0/24` и других VPN клиентов).

## 1. Развертывание

```bash
docker-compose down -v
docker-compose up -d --build
```

После запуска сайт **не будет** доступен по публичному IP сервера.
Он доступен **только** внутри туннеля.

## 2. Как зайти на сайт

1.  Подключитесь к VPN (вы должны получить IP из диапазона `10.60.0.x`).
2.  Откройте в браузере: `http://172.25.0.2`

> **Почему IP изменился?**
> Мы используем Docker-сеть `172.25.0.0/24`, чтобы она не конфликтовала с вашей VPN-сетью `10.60.0.0/24`. Маршрутизация на сервере автоматически перенаправит ваш запрос из VPN в Docker.

## 3. (Опционально) Использование красивого IP 10.60.0.3

Если вы очень хотите открывать сайт по адресу `http://10.60.0.3`, вы можете добавить правило переадресации (NAT) на сервере:

```bash
# Выполнить на хосте (root)
iptables -t nat -A OUTPUT -d 10.60.0.3 -p tcp --dport 80 -j DNAT --to-destination 172.25.0.2:80
```
После этого вы сможете заходить на `10.60.0.3`, и сервер сам перебросит вас на контейнер.
